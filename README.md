# Гравитационное влияние рельефа: веб-интерфейс

Streamlit-интерфейс для [API-сервиса](https://github.com/tester170/Gravity_API_Service). Пользователь загружает CSV с координатами и подготовленными признаками рельефа, просматривает исходные данные и отправляет их на сервер. Сервис применяет обученную модель, возвращает численные результаты и интерактивную карту. Модель и расчётный код в этом проекте не дублируются.

Если свой файл не выбран, используется `data/terrain_demo.csv`. Для другого сервера измените адрес в поле интерфейса. Сервер должен поддерживать `POST /predict` с ответами `json` и `html`, как в проекте по теме 3.

## Запуск

```bash
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m streamlit run app.py
```

В macOS и Linux создайте окружение командой `python3.12 -m venv .venv`, а вместо `.venv\Scripts\python` используйте `.venv/bin/python`. Для входного CSV нужны поля `latitude`, `longitude`, `elevation_m`, `slope`, `curvature`, `tpi_7`, `tpi_31`, `tpi_121`, `roughness_7`, `roughness_31`, `relief_31`. Это подготовленные признаки, а не исходная цифровая модель рельефа.

Результаты можно скачать в виде CSV, GeoJSON с расчётными точками и самостоятельной HTML-карты. Спутниковая подложка карты загружается из сети.
